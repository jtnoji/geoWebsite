## 1. The recommendation: Ten Runs

**Domains free:** `tenruns.com` $11.25 · `tenruns.co` $4.99 · `tenruns.io` $37.99 ·
`tenruns.ai` $160/2yr · `tenrunsgeo.com` $11.25

Buy the .com and .co, park the rest.

The name is the methodology. `/how-it-works` already says it: "AI answers change
between runs. A single fetch is a coin flip. We sample repeatedly and report rates.
Anyone showing you a single-run AI rank is measuring noise." That is the whole
differentiator, and Ten Runs puts it on the business card.

It also solves the honesty problem structurally. The site cannot promise placement,
so the brand has to promise rigor instead. "Ten Runs" promises rigor and nothing
else. It is the only name on this list that a competitor cannot copy without
adopting the discipline.

Practical marks:

- Two syllables, no spelling on a call, no jargon. An SMB owner gets it.
- Works in cold email: "We asked ten times. Here is what came back."
- Not boxed into audits, so it survives the shift to Ongoing GEO.
- Fits the locked voice: plain words, no filler, no em dash needed anywhere.

**The risk, stated plainly.** It encodes a specific number. If sampling depth
changes to 20, the name reads as a stale spec. Two mitigations: never publish "we
always run exactly ten" as a promise, and treat the name as a stance (sample
repeatedly) rather than a parameter. Category and copy already support that reading.

Second risk: out of context it can read as running or cricket. The tagline fixes it
on first contact.

Suggested tagline: **Ten Runs · AI visibility, measured.**
Or, closer to the house voice: **We ask ten times. You get numbers, not vibes.**

No trademark or company conflict surfaced for "Ten Runs" or "TenRuns."

## 2. Runner-up: Crestgauge

**Domains free:** `crestgauge.com` $11.25 · `crestgauge.ai` $160/2yr

A crest gauge measures the height of water over a weir. The design system locked on
2026-07-20 is literally called "weir," so the name and the visual identity come from
the same idea without anyone having to explain the joke.

It sounds like a measurement firm that has existed for forty years. In a field of
Profound, Peec, Otterly and Scrunch, that reads as the adult in the room, which is
the positioning.

**The risk.** It is not self-evident. It needs one line of explanation on the About
page, and it does no work in a cold subject line. Strong brand, weak first
impression.

Whole family is free if you like the direction: `weirpoint.com`, `weirline.com`,
`weirmark.com`, `weirfield.com`, all $11.25.

## 3. Safe choice: Answer Audits

**Domains free:** `answeraudits.com` $11.25 · `answeraudits.ai` $160/2yr

Maximum clarity, zero explanation. It survives a cold subject line better than
anything else on this list.

**Two real problems.** It is generic, which makes it hard to defend as a trademark
and easy for a competitor to sit next to. And it names the audit, which is the way
in, not the product. The 2026-07-25 decision was that Ongoing GEO is what the
business is aimed at. Naming the company after the loss leader fights that.

Rank it third for that reason, not because it reads badly.

## Landscape note

Named competitors in the space right now: Profound, Peec, Otterly, Scrunch,
Evertune, AIVO, Ayzeo, Rankability, Brandi, Surmado. The pattern is coined,
abstract, slightly playful. Nobody in the set is named after their method.

That is an opening. A plain, methodology-rooted name is differentiated here purely
by being unlike the others, and it matches the honesty positioning that the whole
site is built on. It is also why I would not pick a coined name: you would be the
eleventh invented word in a category of invented words.

## When the name lands

Everything below is already staged for a one-file swap, by design.

- `lib/site.ts`: `BRAND`, `DOMAIN`, `EMAIL`, and `NAP.businessName` follows `BRAND`.
  Nothing else in the codebase hardcodes it.
- Re-run `scripts/make-brand-assets.py`. Until then every link shared on LinkedIn or
  Slack previews as "[Brand]". Needs `npm run build` first so the font is present.
- `website-plan.md` §6: move "Brand name + domain" from Still open to Decided, same
  commit as the code change.
- Sending domain: SPF, DKIM and DMARC before the first teaser email. Report delivery
  is the product.
- DNS CAA record once the domain is bought.
- HSTS preload submission at hstspreload.org, only once apex and subdomains are
  HTTPS only.
- `npm run build && grep -r "\[Brand\]" out/` must return nothing.
- Gate as always: `npm run build && npm test && npm run lint`.
